## Overview
This component focuses on implementing Explainable AI (XAI) techniques and developing an interactive web-based decision-support dashboard to present tea harvest predictions across Sri Lankan regions.
Using the outputs from the weather forecasting and yield prediction models, this component translates complex machine learning predictions and feature contributions into clear, actionable insights to help tea estate managers and producers plan labour, transportation, and factory processing.
## Objectives
Apply Explainable AI (XAI) techniques to identify and measure the impact of key weather and historical features on yield predictions.   
Design and develop an interactive, user-friendly web dashboard using Streamlit for non-technical end users.   
Display tea yield estimates alongside historical weather records, weather forecasts, and regional comparisons.   
Validate dashboard accuracy to ensure displayed predictions and explanations remain consistent with underlying model outputs.
## Expected Outputs
Interactive Streamlit web-based decision-support dashboard.
Regional yield prediction views paired with historical and forecasted weather trends.
## Technologies and Tools
- Python
* Streamlit
- Matplotlib, Seaborn, or Plotly
* SHAP (Explainable AI)
- Pandas and NumPy
