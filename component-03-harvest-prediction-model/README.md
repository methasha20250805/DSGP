# Component 03 – Harvest Prediction Model Training and Comparison

## Overview

This component focuses on developing, training, evaluating, and comparing multiple machine learning models to predict monthly tea production across Sri Lankan districts.

Using the processed tea production and weather datasets, different machine learning algorithms will be implemented to identify the most suitable model for accurate and reliable tea harvest prediction.

## Objectives

- Prepare the integrated dataset for machine learning.
- Select relevant features for harvest prediction.
- Implement and train multiple machine learning models.
- Evaluate model performance using appropriate evaluation metrics.
- Compare the performance of different models.
- Perform hyperparameter tuning to improve model performance.
- Identify and select the best-performing model for the prediction system.

## Methodology

1. **Data Preparation:** Prepare the processed dataset for model training and testing.
2. **Feature Selection:** Identify relevant production and weather-related features.
3. **Model Development:** Implement and train multiple machine learning algorithms.
4. **Model Evaluation:** Evaluate models using metrics such as MAE, RMSE, and R².
5. **Model Comparison:** Compare model performance to identify the most suitable algorithm.
6. **Model Selection:** Select and save the best-performing model for integration into the overall system.

## Expected Outputs

- Trained machine learning models.
- Model performance evaluation results.
- Comparative analysis and visualisations.
- Selected best-performing model.
- Prediction results for monthly tea production across Sri Lankan districts.

## Technologies and Tools

- Python
- Google Colab
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn

## Integration

The selected model and its prediction functionality will be provided to **Component 04 – Decision Support Application with Explainable AI (XAI)** for integration into the overall Sri Lankan Tea Production Prediction System.
