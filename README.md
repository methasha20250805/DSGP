# Weather-Driven Forecasting of Tea Harvest in Sri Lanka: A Comparative Decision-Support System

## Project Overview

The **Sri Lankan Tea Production Prediction System** is a data-driven project that aims to analyse the impact of weather conditions on tea production in Sri Lanka and predict future tea harvest trends.

The system integrates historical tea production and weather datasets with data engineering, statistical analysis and machine learning techniques to generate meaningful insights and harvest predictions. It also incorporates a Decision Support Application with Explainable Artificial Intelligence (XAI) to help users understand prediction results and the factors influencing them.

## Problem Statement

Tea production in Sri Lanka is highly influenced by changing weather and climatic conditions. However, analysing the relationship between these factors and predicting future harvest trends remains challenging.

This project aims to address this challenge by developing an integrated system that analyses weather impacts, predicts tea harvests, and provides interpretable insights to support data-driven decision-making.

## Project Objectives

- Analyse historical tea production and weather data.
- Identify the impact of weather conditions on tea harvesting.
- Develop and compare machine learning models for harvest prediction.
- Develop an integrated decision support application.
- Incorporate Explainable AI to interpret model predictions and identify influential factors.

## Dataset Information

The project utilises:

- **Tea Production Data:** Historical tea production datasets collected from six tea factories in Sri Lanka.
- **Weather Data:** Historical daily weather data obtained from the Department of Meteorology, Sri Lanka, including rainfall, temperature and humidity.

These datasets are used for data integration, weather impact analysis and harvest prediction.

Each component folder contains its respective implementation, notebooks, outputs and documentation.
